# GPA778: Algorithmes embarqués en robotique - ÉTS Montréal.

This repository contains my laboratory sessions, custom ROS 2 packages, and robotics integration projects developed during the **GPA778 -  Algorithmes embarqués en robotique** course at École de technologie supérieure (ÉTS Montréal). For more information visit: 
https://www.etsmtl.ca/en/study/courses/gpa778 (French)  

## 🛠️ Workspace Structure
- `src/`: Contains all custom ROS 2 Python/C++ packages developed for labs and final integration.

## 🚀 Development Workflow
1. Code development and testing on target hardware (Raspberry Pi 4 via SSH).
2. Version control and tracking managed locally on development workstation.
3. Automated backup and portfolio showcasing via GitHub.
